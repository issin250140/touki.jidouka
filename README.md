# 土地探しツール (land_finder.py)

緯度経度を入力すると、
1. 住所を特定し（HeartRails Geo APIで逆ジオコーディング）、
2. その座標を「[eMAFF農地ナビ](https://map.maff.go.jp)」の地図データに直接問い合わせて、
   - 所在地番
   - 地目
   - 面積
   - 農振法区分（農振区分）

   を取得し、CSVに保存する**完全自動**のツールです（ブラウザ操作・手動クリック不要）。

## セットアップ

```bash
pip install -r requirements.txt
playwright install chromium
```

## Web画面から使う（おすすめ）

座標を1つの入力欄（例: `37.7700, 139.0500`）に貼り付けるだけで検索でき、
結果は一覧表にまとまって表示されます。Googleマップで座標をコピーした
`(37.7700, 139.0500)` のような括弧付き形式もそのまま貼り付けられます。

```bash
python app.py
```

自動でブラウザが開き、次のURLが表示されます（手動で開く場合はこちらへ）:

```
http://127.0.0.1:5000
```

- 「検索する」で入力した座標を調べ、結果が表の一番上に追加されます。
- 「結果をCSVでダウンロード」でこれまでの結果をまとめてCSV保存できます。
- 「結果をクリア」で一覧表をリセットします。
- **このURLは、このアプリを起動しているパソコンの中だけで有効な
  「ローカルURL」です。** 他の人のパソコン・スマホから直接開くことは
  できません。同じWi-Fi/LAN内の他端末や外部の人と共有したい場合は、
  別途サーバーへのデプロイが必要になります（ご相談ください）。
- 終了するときは、起動したターミナルで `Ctrl+C` を押してください。

## 特定の人にだけ共有する

パスワードで保護した状態でインターネット上に公開し、自分でいつでも
共有をやめられるようにする手順は [DEPLOY.md](DEPLOY.md) にまとめています。

ローカルで動かす場合でも、環境変数 `SITE_PASSWORD` を設定すると
同じパスワード保護がかかります（未設定なら今まで通りパスワード無しです）。

```bash
# PowerShellの例
$env:SITE_PASSWORD = "好きなパスワード"
python app.py
```

## コマンドラインから使う（CSV一括処理など）

### 単発（緯度経度を1組だけ調べる）

```bash
python land_finder.py --lat 37.9161 --lon 139.0364
```

### 複数まとめて（CSV一括処理）

`input_sample.csv` のように `lat,lon` の2列のCSVを用意してください。

```bash
python land_finder.py --csv input_sample.csv --output result.csv
```

結果は指定したCSV（Excelでそのまま開けるUTF-8 BOM付き）に保存されます。

### 動作を目で確認したいとき

```bash
python land_finder.py --lat 37.7700 --lon 139.0500 --show-browser
```

`--show-browser` を付けるとブラウザ画面が表示されます（普段は不要）。

## 仕組み

農地ナビの地図（Mapbox GL）は、農地の区画ポリゴンのデータ自体に
「所在地番・地目・面積・農振法区分」をプロパティとして持っています。
このツールはブラウザを裏で自動操作して指定座標付近の地図データを読み込ませ、
**地図をクリックせずに**そのプロパティを直接読み取ります。そのため
無人・高速・バッチ処理が可能です。

指定座標に最も近い農地区画を「最寄り区画」として採用し、その区画までの
距離(m)もCSVに出力します。距離が離れている場合（初期値: 100m超）は
note列に注意書きが入ります。

## 出力される列

| 列名 | 内容 |
|---|---|
| lat, lon | 入力した緯度経度 |
| address | 逆ジオコーディングで得た住所（町丁目レベル） |
| 所在地番 | 農地ナビ上の所在地・地番 |
| 地目 | 田・畑・樹園地など |
| 面積(m2) | 登記簿ベースの面積（㎡） |
| 農振区分 | 農振法区分（青地／白地／農振地域外など） |
| 距離m | 入力座標から最寄り農地区画の中心までの距離 |
| 近隣区画数 | 読み込んだ範囲内で見つかった農地区画の総数 |
| note | 補足（該当なし・距離が離れている場合の注意など） |

## 注意点（重要）

- 表示される「面積」は登記簿ベースの参考値であり、法的な証明力はありません。
  正式な確認は現地の農業委員会等にお問い合わせください（農地ナビの利用規約より）。
- 指定座標の近くに農地ナビ上の農地が登録されていない場合（農地でない土地、
  市街化区域内の農地など、そもそも農地ナビの公開対象外の土地を含む）は
  「該当なし」になります。
- 農地ナビには自動化ツール（ヘッドレスブラウザ）を検知して拒否する仕組みが
  あるため、通常のブラウザに近い形でアクセスするようにしています。
  農水省の利用規約には「サーバへ過度な負荷を与える通信は予告なく遮断することが
  ある」旨の記載があります。**個人の土地探し用途を想定しており、大量・高頻度の
  アクセスは行わないでください**（スクリプトは1件ごとに数秒間隔を空けています。
  `REQUEST_INTERVAL_SEC` で調整できます）。
- 住所は町丁目レベルの逆ジオコーディングのため番地までは厳密に一致しませんが、
  農地の検索自体は入力した緯度経度そのもので行っているため、農地の特定精度には
  影響しません。

## ファイル構成

- `app.py` — ローカルWebアプリ（入力欄＋結果一覧表、ブラウザで使う版）
- `land_finder.py` — コマンドライン版（CSV一括処理向け、`app.py`からも共通利用）
- `requirements.txt` — 依存パッケージ
- `input_sample.csv` — 一括処理用の入力サンプル
